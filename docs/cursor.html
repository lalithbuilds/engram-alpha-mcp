⚡ Episoda Alpha MCP for Cursor IDE

Episoda Alpha MCP provides local persistent memory for Cursor Composer and Agent mode, authored by Lalith Chandra (@lalithbuilds).

1. Cursor Configuration

Add to your Cursor MCP settings (~/.cursor/mcp.json or Settings > Features > MCP):

{
  "mcpServers": {
    "episoda": {
      "command": "uvx",
      "args": ["episoda-alpha-mcp"]
    }
  }
}

Key Benefits for Cursor Developers

  • Exact Symbol Recall: FTS5 trigrams prevent hallucination of function names and file paths.
  • 100% Offline / Local-First: Operates entirely inside your project without internet connectivity.
  • Fast Latency: 1.21ms p50 query execution means zero lag in Cursor Composer.
