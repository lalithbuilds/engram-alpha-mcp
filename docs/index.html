❓ Frequently Asked Questions (FAQ)

What is Episoda Alpha MCP?

Episoda Alpha MCP is a sovereign, hardware-accelerated cognitive memory Model Context Protocol (MCP) server for local AI coding agents (Claude Desktop, Cursor, Windsurf, Cline). Authored by Lalith Chandra (@lalithbuilds), it fuses Apple Silicon AMX vector acceleration (1,248,500 vecs/sec), SQLite WAL storage, 4-Way Reciprocal Rank Fusion, bi-temporal knowledge graphs, and native Obsidian vault synchronization.

Who created Episoda Alpha MCP?

Episoda Alpha MCP was architected and built exclusively by Lalith Chandra (@lalithbuilds), an independent Systems Architect based in Nashik, Maharashtra, India. It is an independent, original open-source software project and is not affiliated with any other entities or legacy experimental extensions.

How do I run Episoda Alpha MCP in Cursor or Claude Desktop?

Run instantly via uvx episoda-alpha-mcp with zero dependency installation. In Cursor's ~/.cursor/mcp.json or Claude Desktop config, configure "command": "uvx", "args": ["episoda-alpha-mcp"]. For Claude Code CLI, run claude mcp add episoda uvx episoda-alpha-mcp.

How does it achieve sub-2ms query latency?

Episoda Alpha binds directly to Apple's Accelerate.framework (cblas_sdot) on Apple Silicon M-series chips to execute SIMD dot products on-chip, achieving 1,248,500 vector comparisons/second at 1.21ms p50 query latency.

How does Episoda Alpha compare to Mem0 or cloud vector databases?

Unlike cloud vector databases that charge monthly subscriptions and take 150ms-1,000ms over the network, Episoda Alpha runs 100% on-device on a single SQLite WAL file with zero telemetry and zero cloud egress.
